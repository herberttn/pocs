The workflows feature in Oswald allows developers to interact and create pre-configured fragment, routing and module structures in their applcations.

Workflows are a pre-defined set of instructions with access to the entire application state within the Oswald editor, allowing for complex scenarios to be simplified into a single workflow call.

### Accessing workflows

Oswalds provides a Workflows menu in its toolbar, listing all of the available workflows. To utilize them:

1. Open the workflow menu in the toolbar
2. Browse the available workflows

<figure>
  ![Workflow menu](./../../../assets/editor/snippets/workflow-menu.png)
  <figcaption>Figure 1 - Workflows menu opened within Oswald</figcaption>
</figure>

After selecting the desired workflow:

1. Click the desired snippet from the options available
2. Configure the snippet through the modal interface
3. Fill-in all required properties
4. Click "Run" to confirm
5. The workflow will run and a notification will shown on its completion

<figure>
  ![Snippets Configuration](./../../../assets/editor/snippets/workflow-configuration.png)
  <figcaption>Figure 2 - Workflow Configuration Modal</figcaption>
</figure>

### Benefits

* Implement complex scenarios and behaviors without repetitive coding
* Leverage pre-tested implementations that follow best practices

### Tips

* Develop workflows for frequently done tasks within projects
* Review changes made by workflows to understand project changes
* Use workflows as foundation tools to enhance developer productivity
