# Internationalization (i18n)

Internationalization is the process of designin and developing applications that can be adapted to various languages and regions without requiring changes to the source code. In modern applications, i18n is essential for:

* Enabling applications to serve users across different countries and languages preferences
* Providing content in users' native languages improves comprehension, reduces cognitive load, and creates more inclusive experience
* Going beyond simple translation to respect regional formatting convention for dates, numbers, currencies and other locale-specific data
* Separating translatable content from application logic makes it easier to add new languages or update existing translations without modifying code
