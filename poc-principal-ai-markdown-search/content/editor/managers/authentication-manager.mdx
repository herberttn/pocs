The Authentication Manager allows developers to configure authentication settings through the Oswald UI.

### How to use

1. Access the Authentication Manager by using the Spotlight feature in Oswald.
2. Type `>Open authentication manager` as shown in Figure 1.
3. The Authentication Manager interface will open, displaying all available settings, as shown in Figure 2.
4. Modify the value of specific settings according to your requirements.
5. Save your changes.
6. The updated settings will be applied during the application bootstrap process.
