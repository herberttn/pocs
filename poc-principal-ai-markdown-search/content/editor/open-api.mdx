The OpenAPI Schema Integration feature enables linking existing OpenAPI schema endpoints through the Oswald editor preferences. When connected, this feature extends the editor's functionality in two key ways:

1. It provides search capabilities for specific endpoints defined in the schema
2. It makes schema response fields available when configuring components, specifically for editor nodes that have a parent which uses an OpenAPI path as its endpoint

### How It Works

When an OpenAPI schema is linked in the editor preferences, Oswald parses the schema definition to understand available endpoints and their response structures. This integration provides context-aware assistance during development by making API information readily available.

### Benefits

* Streamlined API discovery through in-editor endpoint search
* Simplified component configuration using schema response fields
* Reduced context switching between documentation and implementation
* Improved accuracy when working with API responses

### Getting Started

To enable this feature, the OpenAPI schema endpoint must be specified in the editor preferences menu. Once configured, enhanced functionalities become available throughout the editor interface.

### Examples

#### API Endpoint Configuration

The first example demonstrates the endpoint configuration process in a ⁠Fetch component:

1. Upon opening the endpoint configuration dialog, an enhanced search interface appears
2. The interface displays available endpoints from the linked OpenAPI schema
3. Selecting an endpoint automatically populates the URL field with the correct path
4. Parameter fields are dynamically generated based on the schema definition

This schema-aware approach eliminates the need to manually reference API documentation when configuring endpoints.
