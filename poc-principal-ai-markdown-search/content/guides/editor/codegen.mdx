Oswald enhances developer productivity through its code generation features, which include various functionalities that automate common tasks. These features encompass tasks such as creating and updating aliases, generating initial controllers, and adding event listeners.

### Configuration

To utilize Oswald's code generation capabilities, certain configurations need to be set up. These configurations define how the generated code will behave and can be customized based on project requirements.  
In this example, the layout created in the [Basic Layout](./basic-layout.mdx)  guide will be used.

### Utilizing generated code for fragments

When a fragment is saved, the Editor automatically creates enumerators that encompass all constants associated with that particular fragment. These constants typically include aliases and the fragment name.
