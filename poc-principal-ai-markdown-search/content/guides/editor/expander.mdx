The Expander component allows you to show/hide content when it is clicked. This guide will create a simple Expander with content inside the fixed area and the expandable area of the component.

### Requirements
This guide assumes previous knowledge of how to [create a basic layout](./basic-layout.mdx).

To start our `Expander` a fragment with the components `Layout` and `Panel` will be used.  

<figure>
  ![Initial Tree](./../../../assets/guides/expander/expander-initial-tree.png)
  <figcaption>Figure 1 - Initial Tree</figcaption>
</figure>

After creating the basic layout, create a `card-container` following the documentation of how to [create a card container](./card-container.mdx), with three components: `CardContainerHeader`, `CardContainerSeparator` and `CardContainerBody`.

The following structure is displayed in the Tree tab.
  <figure>
  ![CardContainer Tree](./../../../assets/guides/expander/expander-card-container-tree.png)
  <figcaption>Figure 2 - CardContainer Tree</figcaption>
  </figure>

### How to use

   1. In the components tab, search for `Expander` and drag it into the `CardContainerBody`.
  <figure>
  ![Create a Expander](./../../../assets/guides/expander/expander-create.gif)
  <figcaption>Figure 3 - Create a Expander</figcaption>
  </figure>

  2. Select the `Properties` tab, you will be presented with all the properties that the `Expander` component contains, change the property `alias` to `main-expander`.

  3. In the components tab, search for `CardContainerZone` and drag it into the `Expander` > `expander-content` area. The content in this area will be always visible.
  <figure>
  ![Create a CardContainerZone](./../../../assets/guides/expander/expander-containerzone.gif)
  <figcaption>Figure 4 - Create a CardContainerZone</figcaption>
  </figure>

  4. Add 2 other components, a `Field` into the `CardContainerZone` and a `Text` component inside the new `Field`. Select the `Properties` tab an change the properties as follow:
     <p>Field:</p>
     - `alias`: `bio-field`
     - `width`: `12`.
     
     <p>Text:</p>
     - `alias`: `bio-text`
     - `value`: as you need.
    
    <figure>
    ![Create a Field](./../../../assets/guides/expander/expander-field.png)
    <figcaption>Figure 5 - Create a Field</figcaption>
    </figure>

  5. Now in the `Expander` > `expander-expandable-content` area, include a new `CardContainerZone` with a new `Field` and `Text` components inside. The content inside the `expander-expandable-content` could be shown or hidden.
    <figure>
    ![Create a new ContainerZone](./../../../assets/guides/expander/expander-containerzone-expandable.gif)
    <figcaption>Figure 6 - Create a new ContainerZone</figcaption>
    </figure>
              
    <figure>
    ![ContainerZone on expandable area](./../../../assets/guides/expander/expander-expandable-tree.png)
    <figcaption>Figure 7 - ContainerZone on expandable area</figcaption>
    </figure>
  
  6. Change the `CardContainerZone` property `alias` for `card-container-zone-expandable` and the `Field` and `Text` properties as follow.

     <p>Field:</p>
     - `alias`: `expandable-field`
     - `width`: `12`.
     
     <p>Text:</p>
     - `alias`: `expandable-text`
     - `value`: as you need.   
    
    <figure>
       ![Final Expander example](./../../../assets/guides/expander/expander-example.png)
       <figcaption>Figure 8 - Final Expander example</figcaption>
    </figure>
  
  7. To preview the result, select `Toggles mode between: editing, previewing` in the Editor.
  <figure>
       ![Expander preview](./../../../assets/guides/expander/expander-preview.png)
       <figcaption>Figure 9 - Expander preview</figcaption>
  </figure>

  8. Expander will be shown as follow:
  <figure>
       ![Final preview](./../../../assets/guides/expander/expander-final-preview.gif)
       <figcaption>Figure 10 - Final preview</figcaption>
  </figure>
