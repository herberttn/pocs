This guide will show how to create customizable cards without needing to create a [custom-component](../creating-component.mdx) by using the `CardContainer` and its related components, using other Oswald components to compose its contents.
This guide will create a single card utilizing all `CardContainer` child components, remembering that the component does not require all of them to work properly, such as lists where only the header and content should be visible.

### Requirements
This guide assumes previous knowledge of how to [create a basic layout](./basic-layout.mdx). .  
To start our `Card Container` a fragment with the components `Layout` and `Panel` will be used.

  ![Initial Tree](./../../../assets/guides/card-container/card-container-initial-tree.png)
  <figcaption>Figure 1 - Initial Tree</figcaption>
</figure>

### Card Container Component

The `CardContainer` component can be composed using the following components:
  - <b>`CardContainerHeader`</b>: Used to compose the card header region.
  - <b>`CardContainerFooter`</b>: Used to compose the card footer region.
  - <b>`CardContainerBody`</b>: Used to compose the card content region.
  - <b>`CardContainerSeparator`</b>: Used to add a separator between card regions.
  - <b>`CardContainerZone`</b>: Used within the regions defined above, this this component has a property called size that receives a value from 0 to 100, having a behavior similar to the behavior of a grid. ex: If we place three `CardContainerZone` in a `CardContainerBody` and set the size values of the first two zones to 50, the third `CardContainerZone` will automatically be below it, as the sum of the first two `CardContainerZone` reaches the value of 100. This functionality is very useful when we are working with a responsive layouts, as we can define different size values for different resolutions.

### Using Card Container

1. In the components tab, search for `CardContainer` and drag it into the panel.

<figure>
  ![Create an card container](./../../../assets/guides/card-container/card-container-create.gif)
  <figcaption>Figure 3 - Create a card container</figcaption>
</figure>


2. Add the `CardContainerZone` to the `CardContainerHeader`.
     - Change the `size` property to `100`.
     - Add the `Text` component inside the `CardContainerZone` and add text in the `Value` property

<figure>
  ![Add a header to the card](./../../../assets/guides/card-container/card-container-create-header.gif)
  <figcaption>Figure 4 - Add a header to the card</figcaption>
</figure>

3. Add the `CardContainerSeparator`, sometimes it may occur that the component is not in the correct position within the component tree, when this occurs we have the possibility of moving the component to the correct position by dragging the component or using the shortcuts `Ctrl + x` and `Ctrl + v`. In the example below, the cut and paste shortcuts were used.

<figure>
  ![Add a separator to the card](./../../../assets/guides/card-container/card-container-separator.gif)
  <figcaption>Figure 5 - Add a separator to the card</figcaption>
</figure>

4. Add the `CardContainerBody` and the `CardContainerFooter`, as done in steps 2 and 3, these two components will be added to compose the card.

<figure>
  ![Add a body and footer to the card](./../../../assets/guides/card-container/card-container-body-footer.gif)
  <figcaption>Figure 6 - Add a body and footer to the card</figcaption>
</figure>

5. With these steps the structure of the `CardContainer` is complete, from this it is possible to customize the card as needed, in the example below 4 text fields and a text in the footer will be added.

<figure>
  ![Add content in the body and footer of the card](./../../../assets/guides/card-container/card-container-body-body-footer-content.gif)
  <figcaption>Figure 7 - Add content in the body and footer of the card</figcaption>
</figure>
