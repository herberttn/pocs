This guide will show how a basic layout containing a title, content and footer can be created by using just the `Layout`, `Panel`, `Text` and `Footer` components.

### How to use

1. With the `Editor` open, create a new `fragment`, click on the `+` sign at the top left side of the editor.
<figure>
  ![Basic fragment with a layout](./../../../assets/guides/basic-layout/basic-layout-new-fragment.png)
  <figcaption>Figure 1 - Basic fragment with a layout</figcaption>
</figure>

2. Select the `Layout` component in the side menu, `Components -> Layout -> Layout ` and drag it to the fragment.
<figure>
  ![Add new Layout](./../../../assets/guides/basic-layout/basic-layout-component-layout.gif)
  <figcaption>Figure 2 - Add new Layout</figcaption>
</figure>

3. Select the `Tree` tab and select the `Layout` component.

4. Select the `Properties` tab, you will be presented with all the properties that the `Layout` component contains, each component has its properties and they may vary depending on the component.

5. Create 2 columns and 3 rows in the layout, by default the layout comes with 3 columns and 3 rows, it is possible to add or remove columns and rows. For this layout we will create a row with the name `header`, a row with two columns, `content-left` and `content-right`, and a row named `footer`.

<figure>
  ![Set layout names](./../../../assets/guides/basic-layout/basic-layout-component-layout-content.gif)
  <figcaption>Figure 3 - Set layout names</figcaption>
</figure>

6. The properties will be defined as:  
6.1 Rows  
#0 = `200px` (header)  
#1 = `auto` (content-left/content-right)  
#3 = `min-content`  
6.2 Columns
#0 = `auto` (content-left)  
#1 = `auto` (content-right)  
<figure>
  ![Define layout properties](./../../../assets/guides/basic-layout/basic-layout-properties.png)
  <figcaption>Figure 4 - Define layout properties</figcaption>
</figure>

7. For each layout region we will add a `Panel` component. The `Panel` component is important, as it acts as a wrapper element, containing flex and alignment properties.
It is common to use the `Panel` component to control content visibility dynamically.  
To add a panel, in the same way as the layout, select the `Panel` component in the `Components` tab and drag it to each region of the layout.

<figure>
  ![Insert a panel into each layout region](./../../../assets/guides/basic-layout/basic-layout-component-layout-content-panel.gif)
  <figcaption>Figure 5 - Insert a panel into each layout region</figcaption>
</figure>

8. The following structure is displayed in the `Tree` tab.
<figure>
  ![Tree example](./../../../assets/guides/basic-layout/basic-layout-tree.png)
  <figcaption>Figure 6 - Tree example</figcaption>
</figure>

<Admonition type="note">
It is a good practice to always define the `alias` property to reflect the name of each component, e.g. `panel-header`, `panel-content-left` and so on, because when there is a need to manipulate these components through a [`Controller`](./codegen.mdx), the component interaction will be more intuitive.
</Admonition>

9. Add a new component to the `panel-header`, in the `Components -> DataDisplay -> Text` tab and drag it to the `panel-header`, our `Tree` will look like this:
<figure>
  ![Insert an text component](./../../../assets/guides/basic-layout/basic-layout-tree-text-1.png)
  <figcaption>Figure 7 - Insert an text component</figcaption>
</figure>

10. Select the `Text` component that we added in the previous step and click on the `Properties` tab, in the `value` property add the title for the page. 
Change the properties of the `Text` component to:
 - set the checkbox `bold`
 - `size` = `xxlg`.
 - `alias` = `text-header`
<figure>
  ![Tree example](./../../../assets/guides/basic-layout/basic-layout-tree-text-2.png)
  <figcaption>Figure 8 - Tree example</figcaption>
</figure>

11. Center the title, in the `Tree` tab select the `panel-header` panel, in the `Properties` tab change the following properties:
  - `alignItems` = `center`
  - `justifyContent` = `center`

12. Repeat the process of adding the `Text` component.
  - Add `Text` to the `content-left` panel
  - Add `Text` to the `content-left` panel

13. Change the alias of each `Text` to:
  - `alias` = `text-contet-left`
  - `alias` = `text-contet-right`

<figure>
  ![Tree example](./../../../assets/guides/basic-layout/basic-layout-tree-text-3.png)
  <figcaption>Figure 9 - Tree example</figcaption>
</figure>

14. Change the `value` property of each `Text` component, `content-left` and `content-right`. Take advantage of this moment to change other properties of the component to understand their behavior.  

15. To finish, add a component to the footer, in the `Components -> Layout -> Footer` tab, drag the Footer component to the `panel-footer` panel.  

<figure>
  ![Add an footer component in the bottom panel](./../../../assets/guides/basic-layout/basic-layout-tree-footer.png)
  <figcaption>Figure 10 - Add an footer component in the bottom panel</figcaption>
</figure>

  Layout will be as follows:

  <figure>
    ![Final layout example](./../../../assets/guides/basic-layout/basic-layout-final.png)
  <figcaption>Figure 11 - Final layout example</figcaption>
  </figure>


16. To preview the result, select `editing, preview` in the Editor

<figure>
  ![Final layout preview](./../../../assets/guides/basic-layout/basic-layout-preview.png)
  <figcaption>Figure 11 - Final layout preview</figcaption>
</figure>
