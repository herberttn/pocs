For scenarios where menu options are necessary, Oswald provides the `ContextMenu` component.

### Requirements
This guide assumes previous knowledge of how to [create a basic layout](./basic-layout.mdx).

To start our `ContextMenu` a fragment with the component `Layout` will be used.  

<figure>
  ![Initial Tree](./../../../assets/guides/context-menu/context-menu-initial-tree.png)
  <figcaption>Figure 1 - Initial Tree</figcaption>
</figure>

<Admonition type="note">
To add the events for the options, you can check the [Codegen](./codegen.mdx) guide for creating the controller.
</Admonition>

### How to use

   1. In the components tab, search for `ContextualBar` and drag it into the `Layout`.
  <figure>
  ![Create a ContextualBar](./../../../assets/guides/context-menu/context-menu-contextualbar.gif)
  <figcaption>Figure 2 - Create a ContextualBar</figcaption>
  </figure>

  2. Select the `Properties` tab, you will be presented with all the properties that the `ContextualBar` component contains, change the property `alias` to `main-contextual-bar` and the `title` for `Context menu`.

  3. Now in the `ContextualBar` > `content` area, include a new `ContextMenu` component.
  <figure>
  ![Create a ContextMenu](./../../../assets/guides/context-menu/create-context-menu.gif)
  <figcaption>Figure 3 - Create a ContextMenu</figcaption>
  </figure>

 4. Click on the `ContextMenu` to open it, and add 2 `Option` components. Change the `value` property to `First Option` and `Second Option` respectively.
  <figure>
  ![ContextMenu Option](./../../../assets/guides/context-menu/context-menu-options.gif)
  <figcaption>Figure 4 - ContextMenu Option</figcaption>
  </figure>

 5. Change the `alias` property to `first-option` and `second-option` according to each component. The following structure is displayed in the Tree tab.
  <figure>
  ![ContextMenu Option Tree](./../../../assets/guides/context-menu/context-menu-options-tree.png)
  <figcaption>Figure 5 - ContextMenu Option Tree</figcaption>
  </figure>

 6. Select the `second-option` component and on tab `Properties` check the option `hasSuboptions`.
  <figure>
  ![ContextMenu Suboptions](./../../../assets/guides/context-menu/context-menu-suboptions.gif)
  <figcaption>Figure 6 - ContextMenu Suboptions</figcaption>
  </figure>

 7. Include a new `Option` component inside the `second-option`. Change the `alias` property to `third-option` as well as the `value` property.
  <figure>
  ![ContextMenu Third Option](./../../../assets/guides/context-menu/context-menu-third-option.gif)
  <figcaption>Figure 7 - ContextMenu Third Option</figcaption>
  </figure>

 8. To preview the result, select `Toggles mode between: editing, previewing` in the Editor.
  <figure>
  ![ContextMenu Preview](./../../../assets/guides/context-menu/context-menu-preview.png)
  <figcaption>Figure 8 - ContextMenu Preview</figcaption>
  </figure>

 9. ContextMenu will be shown as follow:
  <figure>
  ![ContextMenu Final Preview](./../../../assets/guides/context-menu/context-menu-final-preview.gif)
  <figcaption>Figure 9 - ContextMenu Final Preview</figcaption>
  </figure>
