Oswald provides the `ContextualBar` component, that is a type of contextual action bar containing a small set of relevant actions related to a content.
The component consists of two areas, one for actions and another for content.

### Requirements
This guide assumes previous knowledge of how to [create a basic layout](./basic-layout.mdx).

To start our `ContextualBar` a fragment with the component `Layout` will be used.  

<figure>
  ![Initial Tree](./../../../assets/guides/contextual-bar/contextual-initial-tree.png)
  <figcaption>Figure 1 - Initial Tree</figcaption>
</figure>

To add the events for the actions, you can check the [Codegen](./codegen.mdx) guide for creating the controller.

### How to use

  1. In the components tab, search for `ContextualBar` and drag it into the `Layout`. Change the property `alias` to `main-contextual-bar`.
  <figure>
  ![Create ContextualBar](./../../../assets/guides/contextual-bar/create-contextualbar.gif)
  <figcaption>Figure 2 - Create ContextualBar</figcaption>
  </figure>

  2. As mentioned before, `ContextualBar` component has two areas, one for the actions and another for content. The following structure is displayed in the Tree tab.
  <figure>
  ![ContextualBar Tree](./../../../assets/guides/contextual-bar/contextual-tree.png)
  <figcaption>Figure 3 - ContextualBar Tree</figcaption>
  </figure>

  3. Change the property `title` of the `main-contextual-bar` to `Contextual Bar`. 
  
  4. Working first with the actions, in `Components` tab search for `Action` and drag it into the `actions` area. 
  <figure>
  ![Create Action](./../../../assets/guides/contextual-bar/contextual-first-action.gif)
  <figcaption>Figure 4 - Create Action</figcaption>
  </figure>

  5. Select the `Action` component that we added in the previous step and click on the `Properties` tab.
   Change the properties of the `Action` component to:
    - `alias` = `action-edit`
    - `buttonTheme` = `primary`
    - `style` = `text`
    - `text` = `Edit`

  6. To add a button with an icon, include a new `Action` component. Change the properties of the new `Action` component to: 
    - `alias` = `second-action`
    - `buttonTheme` = `secondary`
    - `icon` = `/static/assets/philips-shield.svg` or another.
    - `iconPlacement` = `left`    
    - `style` = `button`
    - `text` = `Second Action`
  
  <figure>
  ![ContextualBar Second Action](./../../../assets/guides/contextual-bar/contextual-second-action.png)
  <figcaption>Figure 5 - ContextualBar Second Action</figcaption>
  </figure>

  7. To show a button just with the icon, change the `style` property to `icon`:
  <figure>
  ![ContextualBar Icon Action](./../../../assets/guides/contextual-bar/contextual-icon-action.png)
  <figcaption>Figure 6 - ContextualBar Icon Action</figcaption>
  </figure>

  8. To add a button as Dropdown, include a new `Action` component. Change the properties of the new `Action` component to: 
    - `alias` = `dropdown-action`
    - `buttonTheme` = `primary`
    - `style` = `dropdown`
    - `text` = `Dropdown`

  9. In the components tab, search for `ActionOption` and drag it into the `dropdown-action`. It's possible to include how many actions are necessary and even options with subactions.
  <figure>
  ![Create ActionOption](./../../../assets/guides/contextual-bar/contextual-actionoption.gif)
  <figcaption>Figure 7 - Create ActionOption</figcaption>
  </figure>

  10. Change the `alias` property of the `ActionOption` to `first-option` and the `text` property to `First option`.
  <figure>
  ![First Dropdown Option](./../../../assets/guides/contextual-bar/contextual-first-dropdown-option.png)
  <figcaption>Figure 8 - First Dropdown Option</figcaption>
  </figure>

  11. On `content` area, include a new `Layout` component with one row and one column. Change the `alias` property to `layout-content`.
  <figure>
  ![ContextualBar content area](./../../../assets/guides/contextual-bar/contextual-content-area.gif)
  <figcaption>Figure 9 - ContextualBar Content Area</figcaption>
  </figure>

  12. In the components tab, search for `Card` and drag it into the `Layout` > `content` area. Change the property `alias` to `card-content`.
  <figure>
  ![ContextualBar Layout](./../../../assets/guides/contextual-bar/contextual-layout-card.gif)
  <figcaption>Figure 10 - ContextualBar Layout</figcaption>
  </figure>

  13. Inside the `Card` content, include a `Panel` and a `Text` component.
  <figure>
  ![ContextualBar Panel](./../../../assets/guides/contextual-bar/contextual-panel.gif)
  <figcaption>Figure 11 - ContextualBar Panel</figcaption>
  </figure>

  14. Change the `alias` property of the `Panel` component to `panel-card-content` and for `Text` to `text-card-content`. The following structure is displayed in the Tree tab.
  <figure>
  ![ContextualBar Final Tree](./../../../assets/guides/contextual-bar/contextual-final-tree.png)
  <figcaption>Figure 12 - ContextualBar Final Tree</figcaption>
  </figure>

  15. To preview the result, select `Toggles mode between: editing, previewing` in the Editor.
  <figure>
  ![ContextualBar Preview](./../../../assets/guides/contextual-bar/contextualbar-preview.png)
  <figcaption>Figure 13 - ContextualBar Preview</figcaption>
  </figure>

  16. ContextualBar will be shown as follow:
  <figure>
  ![ContextualBar Final Preview](./../../../assets/guides/contextual-bar/contextualbar-final-preview.gif)
  <figcaption>Figure 14 - ContextualBar Final Preview</figcaption>
  </figure>
