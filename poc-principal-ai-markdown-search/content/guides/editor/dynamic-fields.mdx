This guide shows how to use the Dynamic Fields component to create dynamic forms, using json to assemble the structure of the form fields.

### Requirements
This guide assumes previous knowledge on how to [create fragments](./basic-layout.mdx).

A fragment with the components `Layout`, `ContextualBar`, `Form` and `DynamicFields` will be used.

<figure>
   ![Initial Tree](./../../../assets/guides/dynamic-fields/dynamic-fields-initial-tree.png)
   <figcaption>Figure 1 - Initial Tree</figcaption>
</figure>

  - Create the controller for the fragment, if necessary, you can check the [Codegen](./codegen.mdx) guide for creating the controller.

### How to use

The Dynamic Field expects to receive a [Metadata](https://github.com/philips-internal/oswald/blob/a30c88369247d13c88e76f8bf9f8d4fa7409bf0a/packages/components/src/components/dynamic-fields/dynamic-fields-types.ts#L20C1-L39C2) object to build the form structure. An example of the expected structure will be given in this guide.

Add a new event when creating the DynamicFields component.
  - Select the `DynamicFields` component.
  - Click on the `Events` tab.
  - Right click the `onMount` event and select `Add event implementation`.

This will create an event listener for when the `DynamicFields` is mounted.

```tsx
@Controller({ fragment: FragmentNames.DYNAMIC_FIELDS_GUIDE })
class DynamicFieldsGuideController {

  @OnMount(DynamicFieldsGuideAliases.DYNAMIC_FIELDS_FORM)
  handleDynamicFieldsFormMount(): void {}

}
```

In the method created, we will use the `HttpService` to make a request to the backend, which will return the DynamicField structure. It is also necessary to `Inject` the `DynamicField` component that was added to the form.

#### DynamicField Inject
In the controller add the Inject of 2 components `Form` and `DynamicFields`.
```tsx
  @Inject(DynamicFieldsGuideAliases.DYNAMIC_FIELDS_FORM)
  declare dynamicField: DynamicFieldsAPI;

  @Inject(DynamicFieldsGuideAliases.MAIN_FORM)
  declare mainForm: FormAPI;
```

#### Request structure of DynamicFields
Change the created method to the following logic:
```tsx
  @OnMount(DynamicFieldsGuideAliases.DYNAMIC_FIELDS_FORM)
  handleDynamicFieldsFormMount(): void {
    void HttpService.get<Metadata>('/api/dynamic-fields').then(response => {
      if (!response.body) {
        console.warn('No metadata found');
        return;
      }

      this.dynamicFieldForm.setMetadata(response.body);
    });
  }
```

#### Adding initial values to the form.
In the [Form](./../../components/form.md) component it is possible to load the values of each field, generally used when editing a form. For this, another method will be implemented in the controller.
  - In the Oswald component tree, select the `Form` component.
  - Click on the `Events` tab.
  - Right click the `onMount` event and select `Add event implementation`.
  - In the created method, the following request will be made to load the form values.

```tsx
void HttpService.get<Record<string, Value>>('/api/dynamic-fields-form-value').then(response => {
   if (!response.body) {
      console.warn('No default values found');
      return;
   }

    this.mainForm.setRecord(response.body);
});
```

<Details summary={<summary>Dynamic Form Guide Controller: <code>dynamic-fields-guide-controller.ts</code> </summary>}>
```tsx
import { Inject } from '@odinjs/odin';

import { DynamicFieldsAPI, FormAPI, Metadata } from '@philips-internal/oswald-ui-components';
import { Value } from '@philips-internal/oswald-ui-core';
import Controller, { OnMount } from '@philips-internal/oswald-ui-core/lib/client/index.js';
import { HttpService } from '@philips-internal/oswald-ui-core/lib/services/index.js';

import { DynamicFieldsGuideAliases, FragmentNames } from '../../codegen/index.js';

@Controller({ fragment: FragmentNames.DYNAMIC_FIELDS_GUIDE })
class DynamicFieldsGuideController {
  @Inject(DynamicFieldsGuideAliases.DYNAMIC_FIELDS_FORM)
  declare dynamicField: DynamicFieldsAPI;

  @Inject(DynamicFieldsGuideAliases.MAIN_FORM)
  declare mainForm: FormAPI;

  @OnMount(DynamicFieldsGuideAliases.DYNAMIC_FIELDS_FORM)
  handleDynamicFieldsFormMount(): void {
     void HttpService.get<Metadata>('/api/dynamic-fields').then(response => {
         if (!response.body) {
            console.warn('No metadata found');
            return;
         }

         this.dynamicFieldForm.setMetadata(response.body);
      });
   }

  @OnMount(DynamicFieldsGuideAliases.MAIN_FORM)
  handleMainFormMount(): void {
      void HttpService.get<Record<string, Value>>('/api/dynamic-fields-form-value').then(response => {
         if (!response.body) {
            console.warn('No default values found');
            return;
         }

         this.mainForm.setRecord(response.body);
      });
   }
}

export default DynamicFieldsGuideController;

```
