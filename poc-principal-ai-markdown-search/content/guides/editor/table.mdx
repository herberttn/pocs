For scenarios where data needs to be presented in a table, Oswald provides the `Table` component, which includes customizable `TableColumn` elements to cover diverse use cases.

### Requirements
This guide assumes previous knowledge of how to [create a basic layout](./basic-layout.mdx).

To start using the `Table`, a fragment with the components `ContextualBar` and `Fetch` will be used.  

### How to use

  1. In the components tab, search for `Table` and drag it into the content area of the `ContextualBar`.

  <figure>
    ![Create a Table](./../../../assets/guides/table/create-table.gif)
    <figcaption>Figure 1 - Create a Table</figcaption>
  </figure>

  2. With the `Table` selected, in the properties tab, set the `keyField` to the property that will be used to identify each item in the `data`, in this case `id`, and the `withExpandedIndicator` to `false`.

  3. In the components tab, search for `TableColumn` and drag it into the `Table`.

  4. Repeat the above step to create additional columns. Then, configure the columns in the Properties tab as follows:

| type | alias | value | entry | alignment | width |
| ---- | ----- | :---: | :---: | :-------: | :---: |
| default | table-column-name | Name | name | left | 150px |
| default | table-column-job | Job | job | left | 150px |
| superscription | table-column-status | Status | status | left | 70px |
| superscription_bar | table-column-legend | - | legend | center | 0px |
| dynamic | table-column-dynamic | Dynamic | dynamic | center | 120px |
| checkbox | table-column-active | Active | active | center | 100px |

  The tree should now look like this:

  <figure>
    ![Table initial tree](./../../../assets/guides/table/table-initial-tree.png)
    <figcaption>Figure 2 - Table initial tree</figcaption>
  </figure>

  5. For the superscription columns, it is also necessary to configure how the superscription will be displayed for each possible value. First, select the `table-column-status` and in the properties tab, add two superscription items:

  - First item: select the color `green`, set the `label` to `Good` and the `value` to `good`.
  - Second item: select the color `red`, set the `label` to `Bad` and the `value` to `bad`.

  <figure>
    ![Configure the status superscription](./../../../assets/guides/table/table-status-superscription.gif)
    <figcaption>Figure 3 - Configure the status superscription</figcaption>
  </figure>

  6. Similarly, configure the `table-column-legend` with the following superscription items:

  - First item: select the color `blue`, set the `label` to `Foo` and the `value` to `foo`.
  - Second item: select the color `yellow`, set the `label` to `Bar` and the `value` to `bar`.
  - Third item: select the color `pink`, set the `label` to `Baz` and the `value` to `baz`.

  <figure>
    ![Configure the legend superscription](./../../../assets/guides/table/table-legend-superscription.gif)
    <figcaption>Figure 3 - Configure the legend superscription</figcaption>
  </figure>

  8. To add content to the `table-column-dynamic` column, a controller will be needed. Create a controller for the fragment using the [codegen](./codegen.mdx#utilizing-generated-code-for-controllers) feature.

  9. In the editor, select the `Table` component and in the events tab, right click the `onDynamicContentRender` event and generate an event implementation. Change the content of the generated function to:

<Details open summary={<summary>Render dynamic column content</summary>}>
```tsx
  @OnDynamicContentRender(TableGuideAliases.TABLE_GUIDE)
  onTableGuideDynamicContentRender(event: RenderEvent): void {
    const { data, entry, render, type } = event;
    const person = data as unknown as Record<string, any>;
    
    if (type === 'column' && entry === 'dynamic') {
      render(() => {
        return (
          <div className="c-table__custom-column-cell">
            {person.status === 'good' ? '👍' : '👎'}
          </div>
        );
      });
    }
  }
```
</Details>

The table will now display emojis based on each person's status.

  10. The dynamic content render event can also be used to render customizable sub rows. To do so, the `withExpandedIndicator` property of the `Table` must be set to `true`, it must have a `keyField` configured and the content can not be grouped. If all conditions are met, change the content of the dynamic content render function to:

<Details open summary={<summary>Render sub rows</summary>}>
```tsx
@OnDynamicContentRender(TableGuideAliases.TABLE_GUIDE)
onTableGuideDynamicContentRender(event: RenderEvent): void {
  const { data, entry, render, type } = event;
  const person = data as unknown as Record<string, any>;

  if (type === 'row') {
    render(() => {
      return (
        <Panel>
          <Text value={`I'm ${person.name} and I work as ${person.job}`} />
        </Panel>
      );
    });
  }

  if (type === 'column' && entry === 'dynamic') {
    render(() => {
      return (
        <div className="c-table__custom-column-cell">
          {person.status === 'good' ? '👍' : '👎'}
        </div>
      );
    });
  }
}
```
</Details>

<Details open={false} summary={<summary>table-guide-controller.tsx</summary>}>
```tsx
import React from 'react';

import { Panel, Text } from '@philips-internal/oswald-ui-components';
import { Controller, OnDynamicContentRender } from '@philips-internal/oswald-ui-core/decorators';
import type { RenderEvent } from '@philips-internal/oswald-ui-core/events';

import { FragmentNames, TableGuideAliases } from '../codegen/index.js';

@Controller({ fragment: FragmentNames.TABLE_GUIDE })
class TableGuideController {
  @OnDynamicContentRender(TableGuideAliases.TABLE_GUIDE)
  onTableGuideDynamicContentRender(event: RenderEvent): void {
    const { data, entry, render, type } = event;
    const person = data as unknown as Record<string, any>;

    if (type === 'row') {
      render(() => {
        return (
          <Panel>
            <Text value={`I'm ${person.name} and I work as ${person.job}`} />
          </Panel>
        );
      });
    }

    if (type === 'column' && entry === 'dynamic') {
      render(() => {
        return (
          <div className="c-table__custom-column-cell">
            {person.status === 'good' ? '👍' : '👎'}
          </div>
        );
      });
    }
  }
}

export default TableGuideController;
```
</Details>
