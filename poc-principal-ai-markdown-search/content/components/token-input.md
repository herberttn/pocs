# `TokenInput`

The goal of this component is to allow the insertion of different tokens in a single input.

### Composing

To compose and set the token input, just drop them through Oswald inside a configured field of a [Form](./form.md) and the input will appear inside it.

A complete example of the full composition capabilities of the `TokenInput` can be found at its [samples module](pathname:///../sample/application/token-input).
