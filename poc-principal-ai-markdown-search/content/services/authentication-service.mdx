# `AuthenticationService`

The service offers a comprehensive set of methods to assist developers in meeting their authentication requirements without the need to build their own solution from scratch.

With some extra configuration, the service also provides support for encrypted [Json Web Tokens](https://jwt.io). To enable this in your application see [Encrypted tokens](#encrypted-tokens).

## Encrypted tokens

To enable this feature, the application needs to be [configured](./configuration-service.mdx#setauthenticationconfiguration) with the `encryptedTokens` property set to `true` and ensure the presence of a valid HTTP method and URL for `endpoints.decryptToken`

When making a request to the configured endpoint, the encrypted token is included as a `accessToken` parameter. The service expects a JSON response in the following format, where the `token` property contains the encoded JWT.

<Details summary={<summary>Example configuration for encrypted tokens support</summary>}>
```tsx
function bootstrap(): void {
  ConfigurationService.setAuthenticationConfiguration({
    encryptedToken: true,
    endpoints: {
      decryptToken: {
        method: HttpMethod.POST,
        url: '/api/tokens/decrypt-token',
      },
      ...
    },
    ...
  });
}
```
</Details>

<Details summary={<summary>Expected decryption response</summary>}>
```tsx
interface DecryptTokenResponse {
  token: string;
}
```
</Details>

## Multi-factor Authentication (MFA)

To enable this feature, the application needs to be [configured](./configuration-service.mdx#setauthenticationconfiguration) with valid `multiFactor` endpoints.
Check the interface [AuthenticationConfigurationMultiFactorAuthenticationEndpoints](https://github.com/philips-internal/oswald/blob/main/packages/core/src/services/authentication-service/authentication-service-types.ts) for a description of the endpoints.

<Details summary={<summary>Example configuration for multi-factor authentication support</summary>}>
```tsx
function bootstrap(): void {
  ConfigurationService.setAuthenticationConfiguration({
    encryptedToken: true,
    endpoints: {
      multiFactor: {
        activate: {
          method: HttpMethod.POST,
          url: "/api/mfa/activate"
        },
        validate: {
          method: HttpMethod.POST,
          url: "/api/mfa/validate"
        },
        deactivate: {
          method: HttpMethod.POST,
          url: "/api/mfa/deactivate"
        },
        resend: {
          method: HttpMethod.POST,
          url: "/api/mfa/resend"
        },
        validateActivation: {
          method: HttpMethod.POST,
          url: "/api/mfa/validate-activation"
        }
      },
      ...
    },
    ...
  });
}
```
</Details>

### MFA Flow

#### Example: user with MFA enabled using the Login component

1. User tries to log in the application;
2. Server returns a pre auth token with either: 
   - The property `token_type` with value `PRE_AUTH`;
   - `pre_auth` included in the `roles` property of the token information;
3. Server sends the code to the user;
4. User is requested to enter the code as shown in figure 2;
5. User enters the code and the `multiFactor.validate` endpoint is called to validate the MFA code;
6. User is logged in.

## Methods

### `activateMultiFactorAuthentication`

Activates multi-factor authentication for the user. This method sends a request to the endpoint declared in the `multiFactor.validateActivation` configuration.

#### Example

<Details summary={<summary>Example: <code>Activate MFA</code></summary>}>
```tsx
await AuthenticationService.activateMultiFactorAuthentication({ code: '123456' });
```
</Details>

### `deactivateMultiFactorAuthentication`

Deactivates multi-factor authentication for the user. This method sends a request to the endpoint declared in the `multiFactor.deactivate` configuration.

#### Example

<Details summary={<summary>Example: <code>Deactivate MFA</code></summary>}>
```tsx
await AuthenticationService.deactivateMultiFactorAuthentication({ code: '123456' });
```
</Details>

### `getErrorMessageFromResponse`

Returns the error message from a given response.

#### Example

<Details summary={<summary>Example: <code>Get the error message</code></summary>}>
```tsx

  .catch((error) => {

  });
```
</Details>
